## 1. 立即休息按钮保护期禁用

### 背景

当前点击「立即休息」后有保护时间（防止频繁触发），但 UI 上没有体现，用户可能连续点击导致意外行为。

### 需求描述

#### 1.1 立即休息按钮保护期禁用

- 点击「立即休息」后，进入保护期（时长可配置，默认参考现有保护逻辑）
- 保护期内，按钮变灰（disabled 状态），禁止点击
- 保护期结束后，按钮恢复可点击状态

#### 1.2 稍后/跳过按钮动画期间禁用

- rest 遮罩渐入动画期间（从显示到完全展示），禁用「稍后」/「跳过」按钮
- 渐入动画完成后，启用按钮
- 防止用户在动画过程中误触导致界面闪烁

### 技术要点

- **按钮状态管理**：前端维护 `restButtonDisabled` 等状态，点击后禁用，保护期结束恢复
- **后端事件通知**：rest_start 成功后通过 WebSocket 或轮询通知前端进入保护期，或前端按点击时间计算保护期
- **渐入动画检测**：CSS `animationend`/`transitionend` 或固定延迟（如 300ms）与动画时长匹配

### 验收点

1. 点击立即休息后，按钮立即变灰
2. 保护期内再次点击无效
3. 保护期结束后按钮恢复正常
4. rest 遮罩出现时，稍后按钮在动画期间不可点击
5. 动画结束后按钮可点击

## 2. 新手引导页

### 背景

首次启动应用时，用户可能对功能不了解，需要引导其完成基础配置和使用。

### 需求描述

- 首次启动时显示引导页（可跳过）
- 引导页展示核心功能：休息提醒设置、勿扰模式、统计查看、托盘图标功能
- 引导完成或跳过后，记录标志位，后续启动不再显示
- 支持在设置中「重置引导」

### 技术要点

- **引导状态存储**：使用配置文件或本地存储记录 `has_seen_guide` 标志
- **引导页面设计**：单页多步骤或滑动卡片式，简洁图文说明，「下一步」/「跳过」/「完成」按钮
- **功能入口**：设置页面添加「重新显示引导」选项

### 验收点

1. 首次启动显示引导页
2. 引导可正常完成或跳过
3. 再次启动不再自动显示
4. 设置中可手动触发重新显示
