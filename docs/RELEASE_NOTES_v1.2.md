# EyE Care v1.2

## ✨ 新功能

### 全屏勿扰
新增「全屏时自动勿扰」开关（**设置 → 关闭行为下方**）。

开启后，当检测到前台应用进入全屏（如游戏、全屏视频）时，会**自动切换到勿扰模式**，暂停休息提醒；退出全屏后自动恢复到原来的模式。再也不用担心打游戏、看片到关键时刻被提醒打断。

- 仅「全屏」才触发，**窗口最大化不算全屏**，正常使用不受影响。
- 手动设置的勿扰模式优先，不会被自动逻辑覆盖。
- 默认关闭，需要的话到设置里勾选。

## 🐛 修复

- **休息提醒气泡被其它窗口遮挡**：优化了通知气泡的置顶逻辑，弹出时会强制置于最前，不再被全屏应用、其它置顶窗口压住（且不会抢走当前焦点）。

  > 注：DirectX 独占全屏的游戏在系统层面会盖住一切窗口，这种情况请配合上面的「全屏勿扰」使用——此时提醒会自动暂停、不再弹出。
