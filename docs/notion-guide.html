把每天的用眼汇总
放进自己的 Notion

第一次先手动同步，确认数据正常后，再开启自动同步。你只需要 EyE Care、自己的 Notion 账号和一个专用页面。

开始前，先了解这三件事

  • 数据在你自己的空间里。本手册不含他人的页面链接、密钥或真实统计，也没有预设公共上传位置。
  • 上传的是每日汇总。包括总时长、应用与分类汇总、休息次数；不上传每分钟活动、具体休息时间或完整浏览网址。网站域名汇总默认关闭，可按需勾选。
  • 不需要部署服务器。这里使用 Notion API；不需要 Workers API。免费工作区也有 API 额度，但仍受工作区内容额度与请求限制约束，详见 Notion 官方额度说明。
本机每日汇总→你的 Notion 数据仓库→表格 / 日历 / AI

API 密钥只粘贴到 EyE Care 的密钥输入框。不要贴进页面正文、聊天、公开截图或 GitHub。此 HTML 不收集密钥，也不自动联网加载内容。

1创建自己的 API 连接

  1. 登录 Notion，打开 Notion 开发者门户的连接管理，创建连接。
  2. 选择自己的工作区，创建 Internal / 内部连接，名称可填“EyE Care 同步”。通常需要该工作区的所有者权限。
  3. 在配置中允许读取内容、插入内容、更新内容。此功能不需要读取用户邮箱等信息。
  4. 复制连接的 API token / 内部连接密钥，稍后填进软件。无需创建 OAuth 应用，也无需填写回调网址。

Notion 菜单可能显示“连接”或“Integration”。如果你看到的是 Workers 配置，请返回普通的内部连接；本功能不使用 Worker。

2新建专用页面并授权

  1. 在同一个工作区新建普通空白页，例如“我的用眼统计”。先不要手工创建数据库字段。
  2. 打开页面右上角 ••• → 连接 / Add connections，添加刚创建的“EyE Care 同步”。无需将页面发布到互联网。
  3. 复制这个页面的链接，留到下一步使用。不要复制工作区首页、单条记录或仅某个数据源的链接。

有密钥还不够：连接必须被授权访问目标页面。请只授权专用统计页及其子内容。

3在 EyE Care 中首次同步

打开主界面工具栏的“数据同步”，按下面填写：

Notion 数据仓库链接
第一次粘贴上一步的空白页链接。软件会在该页下创建“EyE Care · 每日数据仓库（正式版）”，以后沿用此链接即可。也可改填软件创建的仓库链接；不要填写自己随意建的表格。
展示页链接（可选）
先填同一个页面链接。“打开统计页”会打开它；留空则打开填写的仓库位置。此项只决定浏览入口，不改变上传目的地。
Notion API 密钥
粘贴第 1 步复制的内部连接密钥。保存后输入框清空属于正常现象；软件会显示已保存状态。
设备名称
起一个容易识别的名字，例如“书房电脑”。不同电脑建议使用不同名称。
日期范围
第一次建议选“今天”。确认正常后可改成最近 7 天或最近 30 天。

点击“保存设置”，再点“立即同步”。用过软件、有统计记录的日期才会新建记录；没有数据时，仓库可能仍是空的。

完成后点“打开统计页”，在 Notion 页面中打开生成的仓库。看到日期、总时长和设备就说明配置成功。再次同步同设备同一天，会更新原记录。

4让表格和日历直接展示在页面里

仓库保存实际数据，视图只是它的展示方式。软件负责创建仓库和同步记录；下面的展示视图需在你的 Notion 中设置一次。

  1. 回到“我的用眼统计”页面，在空白处输入 /linked，选择“数据库关联视图 / Linked view of database”，选刚生成的每日数据仓库。
  2. 将视图设为表格。建议只显示“记录、日期、总时长、休息完成”，并按日期倒序；其他技术字段隐藏即可，不要删除。需要区分电脑时显示或筛选“设备”。
  3. 在该关联数据库的视图菜单中再添加一个日历视图，日期字段选择“日期”；在卡片属性中显示“总时长、设备”。
  4. 可为两个视图添加“数据类型 = 正式数据”筛选。它们读取同一份仓库，后续同步会自动反映在视图中。

如果希望两种视图同时出现在页面上，而不是切换标签，再插入一次相同仓库的关联视图，将第二块设成日历。切勿新建第二个独立仓库来展示同一份数据。

5按自己的习惯开启同步

手动同步
需要时点“立即同步”；软件只处理当前选择的日期范围。
启动后同步一次
每次启动约 15 秒后同步一次。一直放在托盘里不会每 15 秒重复同步。
每天定时同步
按电脑本地时间每天一次，需软件保持运行。首次开启从下一个设定时刻开始；休眠错过后恢复运行可补一次。失败时可手动重试。
多台设备
每台电脑分别填写自己的密钥、设备名称和同一仓库链接。软件按“设备身份 + 日期”更新，各自保留记录，不会用设备名称覆盖另一台电脑。

同一天的不同设备会有多条记录。多设备同时使用或复制历史数据会造成时间重叠，因此不能把各设备时长直接当作去重后的个人用眼时间。

6让 AI 查看统计

在你使用的 AI 应用中连接 Notion，并授权自己的统计页和数据仓库。同步完成后，告诉 AI 统计页名称、日期范围和需要分析的内容即可；无需把 Notion API 密钥发给 AI。

如果不想使用 Notion，也可以在“数据同步”选择日期范围，点击“导出 JSON”，再把导出的每日汇总文件交给 AI。导出前请确认内容是否适合分享。

遇到问题时

找不到页面 / 404 / 没有权限

检查工作区是否相同，并重新在目标页面的“连接”中添加内部连接。填写正确的专用页或软件创建的仓库链接；仅有页面网址并不代表 API 已获授权。

密钥无效 / 401

重新从连接配置复制完整密钥，粘贴到软件并保存。密钥被撤销或更换后，也需要重新填写。

统计库字段不匹配

使用软件自动生成的每日数据仓库，不要删除或改动其字段类型。如果误填了其他表格，改回专用普通页链接，再同步。

点“打开统计页”没有浏览器

点击“复制链接”后手动粘贴到浏览器；检查 Windows 是否已设置默认浏览器，并检查当前展示页链接。

同步后没有新记录

先确认所选日期实际有本地统计。重复同步会更新原记录；内容相同则跳过，不会每点一次都新增一行。

额度不足、请求过快或 Notion 繁忙

不要连续点击。按错误提示稍后重试；工作区内容额度用尽时需先在 Notion 中处理。也可先导出 JSON。

换电脑后需要做什么？

在新电脑重新填写密钥；Windows 加密的凭据不能直接跨用户、跨电脑使用。软件会区分安装位置的设备身份，避免两个安装互相覆盖。
