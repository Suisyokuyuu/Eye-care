# EyE Care

Windows 屏幕时间统计 + 休息提醒的小工具。

这是一个实验性项目：代码 100% 由 GPT 生成；作者主要负责提出需求、调试与验收。

## 功能概览
- 统计前台应用的屏幕使用时间（按应用维度）
- 空闲（Idle）时不计时
- 连续用眼达到阈值后提醒休息
- 托盘图标：快速显示/隐藏、暂停/恢复、退出
- 悬浮窗：展示当前状态 / 当前激活进程（含图标）/ 已连续工作时间

> 注：本项目目前仅支持 Windows。

## 模式说明

本程序包含几种运行模式，用于适配不同场景（以托盘菜单显示为准）：

- **普通模式**
  - 默认模式：按前台应用统计屏幕时间
  - 检测到空闲（Idle）时不计时
  - 连续用眼达到阈值后会提醒休息

- **视频模式**
  - 适合看视频、听课、阅读等“鼠标键盘操作少但仍在用眼”的场景
  - 仍会统计屏幕时间
  - 会尽量避免因为缺少输入而被判定为 Idle
  - 休息提醒逻辑与普通模式相同（若你在设置中启用）

- **勿扰打扰**
  - 仍可统计屏幕时间
  - **不弹出休息提醒/通知**，避免打断工作或会议

> 提示：你可以随时在托盘菜单切换模式。切换只影响之后的统计/提醒行为，不会清空历史数据。

## 怎么用

1. **启动**
   - 运行 `main.py`（源码版）或运行 Release 中zip解压后得到的 `exe`（打包版）

2. **常用操作（托盘图标）**
   - 右键托盘图标打开菜单：  
     **显示/隐藏主窗口、切换模式、退出**

3. **悬浮窗**
   - 悬浮窗用于快速查看：
     - 当前状态和模式
     - 当前激活进程（含图标）
     - 已连续工作时间
   - 通常可在主窗口或托盘菜单打开/关闭（以实际版本按钮为准）

## 导入 / 导出

用于在不同电脑之间迁移数据、或备份统计记录。

- **导出**
  - 在主窗口中点击“导出”（或托盘菜单中的导出项），选择保存位置后生成导出文件
  - 建议将导出文件保存到云盘/移动硬盘作为备份

- **导入**
  - 在新电脑/新环境中启动程序后，点击“导入”（或托盘菜单中的导入项），选择之前导出的文件即可
  - 导入后通常需要点一次“刷新”或重启程序以更新显示（视版本行为而定）

> 提示：导入/导出是为了迁移与备份；日常使用不需要频繁操作。

## EyE Care

A small Windows tool for screen-time tracking and break reminders.

This is an experimental project: the code is 100% generated by GPT, while the author mainly provides requirements, debugging, and validation.

## Features
- Tracks screen time by the **foreground app** (app-level)
- Does not count time while the user is **Idle**
- Sends a reminder when continuous screen time reaches a threshold
- Tray icon: quickly show/hide, switch modes, exit
- Floating window: shows current status / active process (with icon) / continuous working time

> Note: Windows only.

## Modes

This program provides several modes for different scenarios (the tray menu is the source of truth):

- **Normal**
  - Default mode: tracks screen time by the foreground app
  - Does not count time when Idle is detected
  - Triggers break reminders when the threshold is reached

- **Video**
  - For watching videos, attending classes, or reading—situations where you still stare at the screen but have little keyboard/mouse input
  - Still tracks screen time
  - Tries to avoid being marked as Idle due to lack of input
  - Break reminders follow the same rules as Normal (if enabled in settings)

- **Do Not Disturb**
  - Still tracks screen time
  - **Disables break reminders/notifications** to avoid interruptions

> Tip: You can switch modes anytime from the tray menu. Switching only affects future tracking/reminders and won’t clear your history.

## How to Use

1. **Start**
   - Run `main.py` (source version), or unzip the Release package and run the included `exe` (packaged version).

2. **Common actions (Tray icon)**
   - Right-click the tray icon to open the menu:  
     **Show/Hide main window, switch modes, Exit**

3. **Floating window**
   - The floating window is for quick glance:
     - Current status and mode
     - Current active process (with icon)
     - Continuous working time
   - Usually can be toggled from the main window or tray menu (depending on the version).

## Import / Export

Use Import/Export to migrate your data across PCs or to back up your usage history.

- **Export**
  - Click **Export** in the main window (or from the tray menu), choose a save location, and an export file will be generated
  - Store the exported file in cloud storage or an external drive for backup

- **Import**
  - On the new PC/environment, start the app and click **Import** (or use the tray menu), then select the exported file
  - You may need to click **Refresh** or restart the app to update the UI (depending on the version)

> Tip: Import/Export is mainly for migration and backup; you don’t need it frequently.
